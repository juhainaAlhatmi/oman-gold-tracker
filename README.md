# ذهب عُمان | Oman Gold Tracker

## نبذة عن المشروع
تطبيق ويب باللغة العربية لاستعراض أسعار الذهب التجريبية في سلطنة عُمان، وحساب القيمة التقديرية للذهب حسب العيار والوزن، وعرض سجل الأسعار خلال آخر 30 يومًا.

## التقنيات المستخدمة
- Angular
- TypeScript
- Tailwind CSS
- HTML

## مميزات التطبيق
- عرض أسعار عيارات الذهب 18 و21 و22 و24 قيراطًا.
- حساب القيمة التقديرية للذهب حسب الوزن والعيار.
- عرض رسم بياني لتغير الأسعار.
- عرض ملخص السعر الحالي والأعلى والأقل.
- جدول للأسعار خلال آخر 30 يومًا.
- واجهة عربية تدعم اتجاه RTL.
- تصميم متجاوب مع الكمبيوتر والجوال.

## طريقة التشغيل
1. تثبيت Node.js وnpm.
2. فتح مجلد المشروع في الطرفية.
3. تثبيت الحزم باستخدام:

   `npm install`

4. تشغيل التطبيق باستخدام:

   `ng serve`

5. فتح الرابط `http://localhost:4200/` في المتصفح.

## بناء المشروع
لإنشاء نسخة الإنتاج، استخدم:

`ng build`

## ملاحظة مهمة
الأسعار والسجل التاريخي في هذا الإصدار بيانات تجريبية وليست أسعار السوق الفعلية. التطبيق لا يتصل حاليًا بواجهة API خارجية.
